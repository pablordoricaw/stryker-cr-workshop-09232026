## Assets in this directory

- `*.png` — full-color source logos (66x66), the source of truth.
- `*.datauri` — the URL-safe `data:image/png;base64,...` string for each logo,
  ready to drop into a Shields `?logo=` parameter.

## How the encodings were generated

The custom logos are **PNG** (Simple Icons has no entry for these products), so
each is base64-encoded and embedded as a data URI in the Shields `logo` param.
The base64 alphabet includes `+`, `/`, and `=`, which are URL-significant (`+`
becomes a space in a query string), so they are percent-encoded (`%2B`, `%2F`,
`%3D`) — otherwise the logo silently fails to render.

```bash
cd assets/badges
python3 - <<'EOF'
import base64, urllib.parse, pathlib
for key in ["apps","genie","lakebase","lakeflow","unity-catalog"]:
    b64 = base64.b64encode(pathlib.Path(f"{key}.png").read_bytes()).decode()
    uri = "data:image/png;base64," + urllib.parse.quote(b64, safe="")
    pathlib.Path(f"{key}.datauri").write_text(uri + "\n")
EOF
```

All seven badges were verified to return HTTP 200 `image/svg+xml` from Shields.io
with the logo embedded in the returned SVG.
