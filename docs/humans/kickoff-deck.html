Shared workspace, your objects

Everyone builds the whole thing

The work is not split across the team. Every participant builds the entire end-to-end project themselves — the full spine from 00_setup to 07_app. Your team shares one workspace and one existing catalog, so to avoid collisions each person builds inside their own schema with uniquely-named, workspace-scoped objects.

Your private space

  • A personal schema like workshop_<you>
  • Your own UC Volume for landed documents
  • Uniquely-suffixed Genie agent, app, and Lakebase synced table

How grading finds it

workshop.check() resolves your own objects at each checkpoint — it binds to your namespace, so a teammate's same-named agent or table is never mistaken for yours.

No admin needed. You bring an existing catalog — the workshop never creates a catalog and needs no elevated privilege.

What you build, step by step

The checkpoint spine

Nine guided modules of # TODO cells. Each ends with a checkpoint you must pass before the next builds on it.

00setup — provision your schema + UC Volume in your team's existing catalog; seed data.
01bronze_docs — land the PDFs into a bronze documents table.
01bronze_txn — land transactions via Lakebase CDF, with a pre-seeded Delta fallback.
02silver_docs — parse, classify, and extract fields with AI Functions.
03gold — join transactions to extracted docs; build fact table + reconciled mart.
04metadata — auto-generate comments, PI, and domain tags; stage then apply.
05metric_views — author two governed UC Metric Views over gold.
06genie — build a curated, uniquely-named Genie agent over gold + metrics.
07app — wire the provided Streamlit app to Genie + a Lakebase synced table.
99Optional teardown + “build from scratch” stretch toggles.
A few things worth knowing

Details that matter

02 · Document intelligence

Databricks AI Functions do the heavy lifting: ai_parse_document → ai_classify → ai_extract turn raw PDFs into typed rows.

01 · Never blocked on a preview

The Lakebase CDF path is the primary route, but a committed Delta fallback lands the same rows — so no one waits on an admin toggle.

04 · Governance, generated

dbxmetagen runs comment, PI, and domain passes. You stage the metadata for review, then apply it to your gold tables.

07 · Two gaps to fill

The Streamlit app is provided and ships with exactly two gaps — the Genie Conversation API call and the Lakebase read — for you to complete.

Unambiguous progress

Green means you passed

Every checkpoint ends with a workshop.check("<id>") call. It grades the observable state you built — catalog objects, row counts, tags, metric views, Genie answers, synced tables — never how you wrote your notebook.

workshop.check("smoke")  →  [✅ PASS] smoke: workshop.check() is wired up correctly.

No single right answer — many paths reach the same state Targeted feedback — a RED result says what's missing and where to look Run smoke first — it's green from a fresh clone
Everything in the Workspace UI

Get the workshop into your workspace

Pick one path — both land the same files. Then open notebooks/00_setup.py and run it. No local dev environment, no git CLI, no web terminal.

Option A · recommended

Fork & clone as a Git folder

  • Fork the repo to your GitHub account
  • In Databricks: Workspace → Create → Git folder
  • Paste your fork's HTTPS URL and create

Needs a GitHub account linked to Databricks. Lets you commit your own progress.

Option B · fallback

Download a ZIP & upload

  • On GitHub: Code → Download ZIP, then unzip locally
  • In Databricks: Workspace → Import
  • Upload the unzipped folder

Use when you can't connect a Git provider to the workspace.

Then run the bootstrap cell in 00_setup.py, provision your schema + Volume, and run workshop.check("smoke") to confirm you're wired up.
